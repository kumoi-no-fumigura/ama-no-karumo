## 作品について

尼となり焼き物を作って暮らした歌人大田垣蓮月の家集。四季・恋・雑の歌に序と跋を添えて明治の初めに刊行された。ここの本文は『女流文学全集』第4巻の活字本による。

## 底本

- [女流文学全集 第四巻](https://dl.ndl.go.jp/pid/957686)（古谷知新 編・女流文学全集・文芸書院・1919年・p215-235）

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、原本のページごとに段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。
